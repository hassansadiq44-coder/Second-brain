# عقلي الثاني 4.5 — موقع + تطبيق Android متزامنين

نفس الكود (`src/index.html`) يشتغل كموقع (GitHub Pages) وكتطبيق APK (Capacitor). التزامن عبر Supabase بنفس الحساب.
الخط **Cairo** مضمّن محلياً (بدون Google Fonts) فيبقى نفس الخط بالموقع والتطبيق وبدون إنترنت.

## الإعداد (مرة واحدة، حوالي 15 دقيقة)

### 1) Supabase
1. أنشئ مشروعاً في supabase.com.
2. **SQL Editor** ← الصق محتوى `supabase/schema.sql` ← Run. (يرقّي مشروع 4.4 القديم أيضاً بدون فقد بيانات.)
3. **Authentication → Providers → Email**: فعّلها. (اختياري: عطّل Confirm email للتجربة.)
4. **Authentication → URL Configuration**: ضع رابط موقعك في Site URL (مثل `https://اسمك.github.io/second-brain/`).
5. **Project Settings → API**: انسخ `Project URL` و`Publishable key`. لا تستخدم `service_role` أبداً.

### 2) GitHub
1. ارفع هذا المجلد كمستودع جديد.
2. **Settings → Secrets and variables → Actions → Variables** أضف:
   `SUPABASE_URL` و`SUPABASE_PUBLISHABLE_KEY` و`SITE_URL`.
3. **Settings → Pages → Source = GitHub Actions**.
4. شغّل **Actions → Build Android APK → Run workflow**. بعد ~8 دقائق تحصل على:
   - الموقع منشوراً على Pages.
   - ملف APK من **Artifacts → second-brain-apk**.

### 3) APK موقّع (للتحديث فوق النسخة القديمة)
بدون توقيع يُبنى APK تجريبي (debug) ويصلح للاستعمال الشخصي. للتوقيع الثابت:
```
keytool -genkey -v -keystore release.jks -alias sb -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.jks   # الصق الناتج
```
أضف Secrets: `ANDROID_KEYSTORE_B64` و`ANDROID_KEYSTORE_PASSWORD` و`ANDROID_KEY_ALIAS`.
**احتفظ بملف release.jks**: لو ضاع ما تقدر تحدّث التطبيق فوق نسخته.

## الاستعمال
- افتح الموقع والتطبيق ← الإعدادات ← سجّل بنفس بريد الحساب ← «مزامنة الآن».
- بعدها كل جهاز يزامن تلقائياً (التغييرات فقط) كل دقيقتين وعند فتح التطبيق.
- الخزنة: كلمة المرور الرئيسية واحدة لكل الأجهزة. على جهاز جديد: زامن **أولاً** ثم افتح الخزنة (لا تنشئ خزنة جديدة).

## الاختبارات
```
npm install
npm run test:parser          # 34 جملة عراقية
```

## ما الجديد في 4.5 (ملخص)
- **أمان:** قفل الخزنة يمسح البيانات المفكوكة من الذاكرة، البحث لا يلمس الخزنة، إصلاح ثغرة XSS،
  CSP، مكتبة Supabase محلية بدل CDN، PBKDF2 بـ 600k مع تخزين عدد التكرارات (الخزن القديمة تفتح كما هي)، مؤشر ضعف كلمة المرور، إخفاء الرمز تلقائياً بعد 10 ثواني، تنظيف السجلات القادمة من السحابة.
- **مزامنة:** delta sync بساعة السيرفر، حذف المرفقات يُزامَن، «الاستبدال» بالاستيراد يُحذف من السحابة أيضاً، منع إنشاء خزنة ثانية فوق خزنة السحابة، backoff عند الفشل، ما تمسح نماذجك أثناء الكتابة، استرجاع كلمة المرور.
- **الأمر الذكي:** parser جديد: «بعد ساعة / نص ساعة»، الواحدة والحادية عشرة، 12 بالليل، «غداء≠غدا»، أرقام بالكلمات والفواصل، «أمس صرفت»، أسئلة («كم صرفت هالشهر؟»)، تكرار، فصل أوامر، تصنيفات عراقية (مولدة، كارت، إيجار...).
- **عملي:** تكرار المهام + تنبيه مسبق + تأجيل ساعة + علامة «متأخرة»، تذكير نسخ احتياطي بعد 14 يوم، `storage.persist`، فرز حسب التاريخ، بحث عربي مطبّع ويفتح السجل، مزامنة بين تبويبات المتصفح، إملاء صوتي داخل APK.
